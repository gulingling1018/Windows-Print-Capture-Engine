## 1. 项目是做什么的

WPCE（Windows Print Capture Engine）是一个运行在 Windows 10/11 上的**打印监控系统**。

**它能做什么：**
- 实时监听电脑上所有打印机的打印任务
- 自动采集每个打印任务的参数：页数、份数、单双面、颜色、纸张大小、方向等
- 追踪打印任务的生命周期（提交 → 假脱机 → 打印中 → 完成/失败）
- 自动计算打印费用
- 提供图形界面实时查看所有数据

**应用场景：** 打印店计费、企业打印审计、打印行为监控。

## 2. 项目架构概览

整个系统由以下核心模块组成：

```
┌─────────────────────────────────────────────────────────────┐
│                    Windows 打印系统                            │
│  用户打印 → Spooler → 打印机驱动 → 打印机                       │
│                 ↑                    ↑                         │
│     ┌──────────┴──────┐   ┌─────────┴──────────┐             │
│     │  Spooler Watcher │   │  XPS Filter DLL    │             │
│     │  (print_watcher) │   │  (wpce_xps_filter) │             │
│     │  监听打印队列变化  │   │  拦截打印管道数据    │             │
│     └────────┬─────────┘   └─────────┬──────────┘             │
│              │                        │                        │
│              └──────────┬─────────────┘                        │
│                         ▼                                      │
│              ┌─────────────────────┐                          │
│              │   Metadata Merger   │  合并两路数据              │
│              └─────────┬───────────┘                          │
│                        ▼                                       │
│              ┌─────────────────────┐                          │
│              │    Watcher Bridge   │  Qt信号桥接               │
│              └─────────┬───────────┘                          │
│                        ▼                                       │
│              ┌─────────────────────┐                          │
│              │   GUI / CLI 输出     │  wpce_ui.exe / wpce.exe  │
│              └─────────────────────┘                          │
└─────────────────────────────────────────────────────────────┘
```

**两层采集机制：**

| 层级 | 技术 | 采集内容 | 适用场景 |
|------|------|----------|----------|
| 第一层 | Win32 Spooler API | 任务状态、用户名、文档名、页数 | 所有打印机（v3/v4驱动） |
| 第二层 | XPS 过滤器 DLL | PrintTicket（颜色、双面、份数、纸张等真实参数） | 仅 v4 驱动 |

**为什么需要两层？**
- v3 驱动（老式 GDI）：只有第一层能用，参数来自 DEVMODE（可能不准）
- v4 驱动（现代 XPS）：两层都用，PrintTicket 是权威数据源，优先级更高

## 3. 开发环境搭建

### 3.1 必需的工具

| 工具 | 版本要求 | 用途 | 下载地址 |
|------|----------|------|----------|
| **Visual Studio** | 2022 或更新 | C++ 编译器 + IDE | https://visualstudio.microsoft.com |
| **CMake** | ≥ 3.25 | 构建系统 | https://cmake.org/download |
| **Qt** | 6.8.x | GUI 界面框架 | https://www.qt.io/download |
| **Git** | 任意 | 版本管理 | https://git-scm.com |

### 3.2 Visual Studio 安装步骤

1. 下载 Visual Studio Community（免费版）
2. 安装时勾选 **「使用 C++ 的桌面开发」** 工作负载
3. 确保右侧包含以下组件：
   - MSVC v143 - VS 2022 C++ x64/x86 生成工具
   - Windows 11 SDK（最新版）
   - C++ CMake 工具（可选，也可以单独装 CMake）

### 3.3 Qt 安装步骤

1. 下载 Qt 在线安装器
2. 注册/登录 Qt 账号
3. 选择组件：**Qt 6.8.2** → **MSVC 2022 64-bit**
4. 默认安装路径：`C:\Qt\6.8.2\msvc2022_64`

### 3.4 CMake 安装

下载安装包，安装时选择 **「Add CMake to the system PATH」**。

### 3.5 验证环境

打开 PowerShell，运行项目自带的环境检查脚本：

```powershell
cd "D:\code\Windows Print Capture Engine"
.\scripts\check-toolchain.ps1
```

输出中应看到 `cmake`、`msbuild`、`git` 等工具的路径。如果显示 `<missing>`，说明对应工具未正确安装。

## 4. 第一次编译运行

### 4.1 编译核心库和测试（不需要 Qt）

如果你还没装 Qt，可以先编译核心部分：

```powershell
cd "D:\code\Windows Print Capture Engine"

# 方式二：手动 CMake 命令
```

编译成功后，输出在 `build\vs2026-x64\` 目录下。

安装 Qt 后：

```powershell
# 配置（包含 Qt GUI）
cmake --preset vs2026-x64-qt

# 编译 Debug 版
cmake --build build\vs2026-x64-qt --config Debug

# 运行 GUI
.\build\vs2026-x64-qt\src\ui\Debug\wpce_ui.exe
```

| Preset | 说明 | 是否需要 Qt |
|--------|------|-------------|
| `vs2026-x64` | 仅核心库 + CLI | 不需要 |
| `vs2026-x64-qt` | 核心 + GUI | 需要 |

## 6. 如何调试 Debug

### 6.1 使用 Visual Studio 调试（推荐）

#### 方法一：直接打开 VS 解决方案

```powershell
# 先配置 CMake（生成 .sln）
cmake --preset vs2026-x64-qt

# 用 VS 打开解决方案
start build\vs2026-x64-qt\WPCE.sln
```

在 Visual Studio 中：
1. 右侧「解决方案资源管理器」→ 右键 `wpce_ui` 项目 → **设为启动项目**
2. 在代码中点击行号左侧设置断点（红色圆点）
3. 按 **F5** 启动调试
4. 程序会在断点处暂停，可以查看变量值、调用栈

#### 方法二：从 VS Code 调试

如果你用 VS Code，安装 C/C++ 扩展后，按 F5 会自动调用 MSVC 调试器。

### 6.2 调试 CLI 命令行工具

CLI 工具 `wpce.exe` 支持多种命令，方便单独测试：

```powershell
# 查看版本
.\build\vs2026-x64\src\Debug\wpce.exe --version

# 输出示例 JSON（检查序列化格式）
.\build\vs2026-x64\src\Debug\wpce.exe --sample-json

# 监听指定打印机（带详细日志）
.\build\vs2026-x64\src\Debug\wpce.exe --watch-printer "HP LaserJet" "output-dir" --verbose

# 列出当前打印队列中的任务
.\build\vs2026-x64\src\Debug\wpce.exe --list-jobs "HP LaserJet"
```

`--verbose` 参数会输出详细的调试日志，帮助定位问题。

### 6.3 使用 DebugView 查看日志

XPS 过滤器运行在 Spooler 进程中，无法直接打断点。可以用 **DebugView**（微软官方工具）查看日志：

1. 下载 DebugView：https://learn.microsoft.com/en-us/sysinternals/downloads/debugview
2. 以管理员身份运行 DebugView
3. 菜单 → Capture → 勾选 **Capture Win32**
4. 正常使用打印机，DebugView 会实时显示过滤器输出的日志

### 6.4 查看输出数据

捕获的数据保存在输出目录中：

```
data/capture-20260621-143052/
├── jobs/
│   ├── job-42.json              # 任务快照（含元数据）
│   ├── job-42-lifecycle.json    # 生命周期事件
│   └── ...
├── job-HP_Printer-42-pt-metadata.json  # PrintTicket 元数据
└── user_tasks.json              # 用户任务汇总
```

直接打开 `.json` 文件查看采集到的数据。

### 6.5 常用调试技巧

**问题：打印任务没被检测到**
- 检查打印机名称是否完全匹配（大小写敏感）
- 运行 `Get-Printer` 查看系统中的打印机列表
- 确认 Print Spooler 服务正在运行

**问题：参数显示"未报告"**
- v3 驱动只能靠 DEVMODE，某些虚拟打印机不提供完整参数
- v4 驱动需要安装 XPS 过滤器才能获取 PrintTicket

**问题：XPS 过滤器不工作**
- 确认已运行 `install-xps-filter.ps1`（需管理员）
- 确认重启了 Spooler 服务
- 在注册表中检查 `HKLM\CLSID\{B1C8E3F0-2D4A-5B6C-7D8E-9F0A1B2C3D4E}` 是否存在

## 7. 如何添加新功能

以添加一个「打印质量」字段为例，演示完整的开发流程：

### 第 1 步：理解数据流

```
打印任务产生 → Spooler 采集 DEVMODE / XPS 过滤器采集 PrintTicket
              → 数据合并 → UI 显示
```

### 第 2 步：在数据结构中添加字段

编辑 `src/core/data_contracts.h`，在 `MetadataSnapshot` 结构体中添加：

```cpp
FieldValue print_quality;   // 打印质量
```

### 第 3 步：在采集器中提取字段

编辑 `src/collector/metadata_collector.cpp`，从 DEVMODE 中提取：

```cpp
core::FieldValue extract_print_quality(const DEVMODEW& dm)
{
  if (!has_dm_field(dm.dmFields, DM_PRINTQUALITY))
    return make_not_reported();
  return make_reported(std::to_string(dm.dmPrintQuality));
}
```

### 第 4 步：在解析器中解析 PrintTicket

编辑 `src/parser/print_ticket_parser.cpp`，解析 PrintTicket XML：

```cpp
{
  std::string opt = find_feature_option(pt_xml, "psk:PageResolution");
  set_if_present(snapshot.print_quality, map_resolution_option(opt));
}
```

### 第 5 步：在 UI 中显示

编辑 `src/ui/job_detail_panel.cpp`，在参数网格中添加：

```cpp
{QStringLiteral("质量"), &metadata.print_quality},
```

### 第 6 步：编译验证

```powershell
cmake --build build\vs2026-x64 --config Debug
.\build\vs2026-x64\tests\Debug\wpce_parser_tests.exe
.\build\vs2026-x64\tests\Debug\wpce_contract_tests.exe
```

### 第 7 步：添加单元测试

在 `tests/print_ticket_parser_tests.cpp` 中添加测试用例：

```cpp
TEST(PrintTicketParser, ExtractsPrintQuality)
{
  wpce::core::MetadataSnapshot snapshot;
  wpce::parser::parse_print_ticket_xml(kSamplePrintTicket, snapshot);
  EXPECT_EQ(snapshot.print_quality.state, wpce::core::FieldState::Reported);
  EXPECT_EQ(snapshot.print_quality.value, "600 dpi");
}
```

## 8. 如何在其他电脑部署

### 8.1 打包发布版

运行打包脚本，自包含便携包：

```powershell
.\scripts\package-release.ps1
```

输出目录：`release\wpce-portable\`，包含：
- `wpce_ui.exe` — GUI 主程序
- `wpce.exe` — CLI 命令行工具
- `wpce_xps_filter.dll` — XPS 过滤器
- `wpce_config.json` — 配置文件
- `Qt6*.dll` — Qt 运行时
- `msvcp140.dll` / `vcruntime140.dll` — VC++ 运行时
- `Launch-WPCE.bat` — 启动脚本

**目标电脑要求：**
- Windows 10/11 x64
- 不需要安装 Qt 或 Visual Studio
- 需要至少一台本地打印机

### 8.2 安装 XPS 过滤器（关键步骤）

要获取完整的打印参数，必须在目标电脑上安装 XPS 过滤器：

```powershell
# 以管理员身份运行 PowerShell
.\scripts\install-xps-filter.ps1
```

这个脚本会：
1. 复制 DLL 到 `C:\Program Files\WPCE\`
2. 注册 COM 服务器（写入注册表）
3. 设置环境变量 `WPCE_OUTPUT_DIR`
4. 扫描所有打印机驱动，找到 v4 驱动
5. 将过滤器注入到 v4 驱动的打印管道配置中

**安装后必须重启打印服务：**

```powershell
net stop spooler && net start spooler
```

### 8.3 手动部署步骤（不用脚本）

如果脚本不能用，手动部署：

```powershell
# 1. 复制所有文件到目标电脑
# 2. 以管理员注册 XPS 过滤器
regsvr32 "C:\路径\wpce_xps_filter.dll"

# 3. 设置输出目录环境变量（系统级）
[Environment]::SetEnvironmentVariable("WPCE_OUTPUT_DIR", "C:\data", "Machine")

# 4. 重启打印服务
net stop spooler && net start spooler
```

### 8.4 配置文件

编辑 `wpce_config.json` 可以自定义：

```json
{
  "storage": {
    "output_root": "./data",
    "use_timestamp_subdir": true,
    "retention_days": 90
  },
  "pricing": {
    "single_sided_per_page": 0.15,
    "double_sided_per_sheet": 0.25,
    "color_surcharge": 0.50,
    "currency": "CNY"
  },
  "monitoring": {
    "stall_timeout_seconds": 30
  }
}
```

### 8.5 卸载 XPS 过滤器

```powershell
# 注销 COM 服务器
regsvr32 /u "C:\Program Files\WPCE\wpce_xps_filter.dll"

# 重启打印服务
net stop spooler && net start spooler
```

### 9.3 集成/场景测试

#### 第 1 步：创建虚拟打印机

```powershell
# 以管理员运行
.\scripts\setup-virtual-printers.ps1
```

这会创建两个测试打印机：
- **WPCE Sim Printer** — 正常打印机（数据发到 nul:，模拟完成）
- **WPCE Fault Printer** — 故障打印机（连不通的 IP，模拟错误）

#### 第 2 步：运行场景测试

```powershell
# 运行所有场景
.\scripts\run-scenario-tests.ps1

# 运行指定场景
.\scripts\run-scenario-tests.ps1 -Scenario "normal"
.\scripts\run-scenario-tests.ps1 -Scenario "stall"
.\scripts\run-scenario-tests.ps1 -Scenario "high-concurrency"
```

**可用的测试场景：**

| 场景 | 说明 | 预期结果 |
|------|------|----------|
| `normal` | 正常打印 5 个任务 | 全部 completed |
| `fast-disappear` | 任务快速消失 | cancelled/completed |
| `cancel-mid` | 打印中途取消 | cancelled |
| `stall` | 暂停打印机模拟停滞 | stalled |
| `printer-error` | 发到故障打印机 | failed/stalled |
| `high-concurrency` | 50 个任务并发 | completed/cancelled |
| `param-variety` | 不同参数组合 | spooling→completed |

#### 第 3 步：运行完整打印模拟

```powershell
# 运行所有模拟场景（使用真实 Win32 打印 API）
.\scripts\run-print-simulation.ps1

# 只运行冒烟测试
.\scripts\run-print-simulation.ps1 -Scenario smoke

# 自定义参数
.\scripts\run-print-simulation.ps1 -Scenario concurrency -JobCount 50 -Concurrency 10
```

模拟测试会创建真实的 Win32 打印任务，测试覆盖：
- 正常打印流程

## 10. 常见问题排查

### Q: 编译报错「找不到 Qt6」

```
CMake Error: Could not find a package configuration file provided by "Qt6"
```

**解决：** 确认 Qt 安装路径，在 CMake 配置时指定：

```powershell
cmake --preset vs2026-x64-qt -DCMAKE_PREFIX_PATH="C:/Qt/6.8.2/msvc2022_64"
```

### Q: 编译报错「找不到 Windows SDK」

**解决：** 打开 Visual Studio Installer，安装 Windows 11 SDK。

### Q: 运行 GUI 时提示缺少 DLL

**解决：** 确保用 `Debug` 或 `Release` 配置编译，Qt 的 `windeployqt` 会自动复制依赖 DLL。如果还是缺，手动运行：

```powershell
windeployqt.exe build\vs2026-x64-qt\src\ui\Debug\wpce_ui.exe
```

### Q: XPS 过滤器安装后，PrintTicket 数据没有出现

**排查步骤：**
1. 确认重启了 Spooler 服务
2. 确认打印机使用的是 v4 驱动（`Get-Printer | Select Name, DriverName`）
3. 用 DebugView 查看过滤器日志
4. 检查 `WPCE_OUTPUT_DIR` 环境变量是否设置了（系统级）

### Q: 测试时虚拟打印机创建失败

**解决：** 以管理员身份运行 PowerShell，并确保 Spooler 服务在运行：

```powershell
Get-Service Spooler | Start-Service
```

### Q: GoogleTest 下载失败

如果网络不通，CMake 配置时会卡在下载 GoogleTest。解决：

```powershell
# 设置代理
set HTTP_PROXY=http://你的代理:端口
set HTTPS_PROXY=http://你的代理:端口

# 或者手动下载放到 build/_deps/ 目录
```
